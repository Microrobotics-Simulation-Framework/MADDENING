# What's new in v0.4.1

```{versionadded} v0.4.1
```

v0.4.1 (2026-10-13) is a packaging fix. No code changed; everything in the
[v0.4.0 notes](v0.4.0.md) still holds.

## Fixed

- **`pip install maddening[all]` and `maddening[dev]` install from wheels again.**
  In 0.4.0 and earlier, `all` included PyGObject, the Python bindings the
  `streaming` extra uses. PyPI publishes PyGObject as source only, so pip had to
  compile it, and the build stopped with `Dependency "cairo" not found` on a
  machine without the cairo and GObject-introspection development headers. `dev`
  includes `all`, so the development install failed the same way.
  - `all` is now every feature extra except `usd` and `streaming`, plus the
    RunPod and Lambda cloud providers.
  - `streaming` still installs PyGObject. It also needs GStreamer and its WebRTC
    plugins, which come from your system's package manager, not from pip: see
    [Streaming prerequisites](../user_guide/installation.md#streaming-prerequisites).
  - CI now resolves `all` and `dev` from wheels alone on every push, so a
    dependency that needs a build cannot slip back into them.
- **On 0.4.0 or earlier,** name the extras of `all` except `streaming` instead:

  ```bash
  pip install "maddening[viz,terminal,network,api,surrogates,viz3d,gpu-viz,compression,cloud]"
  ```
