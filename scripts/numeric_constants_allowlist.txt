# Small numeric constants in the numerical core, each with what it is relative to.
#
# Read by scripts/check_numeric_constants.py (see its docstring).  One line per
# (file, enclosing scope, literal) with the number of such hits in that scope:
#
#     <path> <qualname> <token>[*<count>]  # <units justification>
#
# A justification says what the number is relative to.  "Dimensionless, a
# fraction of X" or "dtype range: ..." is a justification; "small" is not.  A
# constant that is absolute in a quantity's own units belongs here only with
# the reason it cannot change a result silently, or the registry entry that
# records that it can.  A stale line (no such constant any more, or a different
# count) fails the gate.
