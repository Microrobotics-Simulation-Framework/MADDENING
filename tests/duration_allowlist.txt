# docs/developer_guide/testing_standards.md:
#
#   up to 1 s   fine
#   1-5 s       watch list; optimise when you are in the file
#   over 5 s    mark @pytest.mark.slow (still runs in slow-tests.yml:
#               scheduled 3x a week on main only; on a release branch

#               keep it here with "kept: <why it must run on every push>"

# job. The 4x gap is runner noise: the same test varies 1.7x between runs at
# the median, 3x at the 90th percentile.
